## Interpretation rules

- Interpret CSGB separately from NASA, CALCE, and TRI. Strong CSGB fit is controlled benchmark evidence, not proof of field accuracy.
- TRI's C/80 and C/40 tests are thousands of minutes long, so absolute-minute MAE should be read together with MAPE and `outputs/tri/rate_level_metrics.csv`.
- A four-panel or eight-panel figure may use different axis ranges by dataset. Compare metric labels, not visual slope alone.
- M9 reference labels for real data are deterministic thresholds, not expert annotations.
- Files with `shap` in their names preserve the established output contract. The supplied execution used deterministic Monte-Carlo Shapley values because the optional `shap` package was unavailable; exact TreeSHAP is used when installed.
