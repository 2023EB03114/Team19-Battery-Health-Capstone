PHASE-3 REVISION-2 WINDOWS QUICK START
=====================================

1. Open Command Prompt in the Phase3_Implementation folder.

2. Create the virtual environment:
   py -3.12 -m venv .venv

3. Install the pinned packages:
   .venv\Scripts\python -m pip install --upgrade pip
   .venv\Scripts\python -m pip install -r requirements.txt

4. Run the complete validation suite:
   run_full_validation.bat

   Expected final line:
   VALIDATION SUITE STATUS: PASS

   Expected output contract:
   Datasets: 4
   Held-out prediction rows: 2532
   Graphs: 22
   Persisted models: 8

5. Start the dashboard:
   run_phase3_dashboard.bat

   Then open the local URL printed by Streamlit, normally:
   http://localhost:8501

Existing verified outputs are included in outputs\. Running the suite
regenerates them. The raw public archives are not required because compact
prepared NASA, CALCE, and TRI summaries are included.

To rebuild the prepared TRI summary from the official raw ZIP, follow
PUBLIC_DATA_REPRODUCTION.md. Do not place the 250 MB raw archive in the
submission ZIP.
